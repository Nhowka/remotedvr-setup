APK Setup

Install an APK on an Android device over USB and grant the permissions it asks for. Runs entirely in your browser (WebUSB + ADB); the APK never leaves this computer.

1 · Device

Not connected

Enable USB debugging on the device. Close other ADB tools first: quit Android Studio and run adb kill-server on this computer. Chrome or Edge only.

2 · APK

Download APK For a phone: open this page on the phone, download, then open the file to install (allow "Install unknown apps" for the browser when asked).

3 · Install

On Jaecoo/Chery head units with SOP6/SOP7 firmware pm install is blocked, so it first installs through Android's PackageInstaller (a small helper run with app_process), then falls back to pm install and an install session. If both fail, the APK is copied to the device's Download folder so it can be installed from a file manager, and the log shows the device's reason.

4 · Permissions & setup

Choose an APK to see what it requests.

⚠ items are powerful and off by default – tick them only for apps you trust. Works on its own: use it after installing here or any other way.
